AuraUI Documentation

A high-performance C++20 desktop framework utilizing native webview rendering and embedded Virtual File Systems for compact, single-binary applications.

~480 KB Standalone Binary Pure C++20 HTML5 / CSS3 Zero External DLLs

⚡ Introduction

AuraUI eliminates the bloat of traditional web-based desktop runtimes. While Electron applications bundle a full Chromium browser and Node.js environment exceeding 150 MB, AuraUI links your C++20 business logic directly with the native operating system webview engine (Evergreen WebView2 on Windows).

At build time, all HTML, CSS, JavaScript, SVG, and font assets are embedded directly into your C++ binary as an in-memory Virtual File System (VFS), emitting a single, self-contained .exe that launches instantly without any installers or runtime dependencies.

🏗️ Architecture

Communication between the native C++ engine and the webview interface happens over a bidirectional, type-safe IPC channel:

ARCHITECTURE OVERVIEW 
+-------------------------------------------------------------+
|             Frontend (HTML5, Modern CSS, ES6 JS)            |
|       aura.call("calc", data)  <-->  aura.on("event", fn)   |
+-------------------------------------------------------------+
                              ↕ [Encrypted IPC WebSocket / Pipe]
+-------------------------------------------------------------+
|         Native AuraUI Bridge & In-Memory VFS (vfs.h)         |
+-------------------------------------------------------------+
                              ↕ [Type-Safe nlohmann::json]
+-------------------------------------------------------------+
|             Backend: Pure C++20 Engine (auraui.hpp)         |
|         app.bind()  |  app.emit()  |  Win32 System API      |
+-------------------------------------------------------------+

🛠️ Prerequisites & Setup

Requirement Version Details
Operating System Windows 10 / 11 (x64) Ships with Evergreen WebView2 Runtime pre-installed.
C++ Compiler MSVC 2022 (v143) C++20 enabled (/std:c++20 /O2 /MD /EHsc).
Python 3.10 or newer Powers the CLI asset bundler and build automation.

⚡ Quick Start

Scaffold, run, and compile your first AuraUI desktop application in 4 commands:

POWERSHELL 
# 1. Scaffold a new desktop app
auraui new my-calculator

# 2. Enter project folder
cd my-calculator

# 3. Live development with instant hot-reload
auraui dev

# 4. Compile into a standalone release executable
auraui build
💡 Instant Hot-Reload

In development mode (auraui dev), editing any file in ui/index.html, ui/style.css, or ui/app.js updates live in the window upon refresh (Ctrl + R or F5) without needing C++ recompilation.

💻 CLI Toolchain Reference

auraui new <name>

Initializes a clean boilerplate project configured with modern titlebars, route switching, and event listeners.

auraui dev

Starts the application in development mode with unoptimized compilation and direct disk access to ui/ assets for rapid iteration.

auraui build

Generates vfs.h from the ui/ directory and invokes MSVC with maximum release optimizations (/O2), outputting the single release binary in dist/.

⚙️ C++ Backend Guide (auraui.hpp)

The core framework resides in the single include header auraui.hpp.

Window Lifecycle & App Instance

C++ 
#include "auraui.hpp"

int main() {
    // Initialize window: Title, Width, Height
    auraui::App app("AuraUI Application", 1080, 720);

    // Enforce minimum window bounds
    app.set_min_size(800, 500);

    // Center the window on the active monitor
    app.set_center();

    // Security: permit or block clipboard inspection
    app.allow_clipboard_read(true);

    // Enter application event loop
    return app.run();
}

Express-Style Route Bindings

C++ 
// Bind custom function name
app.bind("add_numbers", [](const auraui::Context& ctx) {
    int a = ctx.get<int>("a", 0);
    int b = ctx.get<int>("b", 0);
    ctx.json({{"result", a + b}});
});

// REST-style route handlers
app.get("/api/status", [](const auraui::Context& ctx) {
    ctx.json({{"status", "online"}, {"uptime_sec", 3600}});
});

app.post("/api/user", [](const auraui::Context& ctx) {
    std::string username = ctx.get<std::string>("username", "Guest");
    ctx.json({{"success", true}, {"user", username}});
});

Pushing Real-Time Events (app.emit)

Send unsolicited background telemetry or notifications to the UI from any thread:

C++ 
app.emit("telemetry", {
    {"cpu_usage", 12.4},
    {"ram_mb", 256.0}
});

Native Win32 File Dialogs & Shell Interop

C++ 
// Native Open File Dialog
std::string path = auraui::open_file_dialog("Open File", "Text Files (*.txt)\0*.txt\0");

// Native Save File Dialog
std::string save = auraui::save_file_dialog("Save Document", "report.pdf");

// Safe External URL Launch (protocol-whitelisted)
auraui::open_external("https://github.com");

🌐 Frontend JavaScript Guide (aura.js)

The client library exposes the global aura API across all windows.

Invoking C++ Backend Functions (aura.call)

JAVASCRIPT 
async function calculateSum() {
    try {
        const res = await aura.call('add_numbers', { a: 25, b: 17 });
        console.log('Answer:', res.result); // 42
    } catch (err) {
        console.error('RPC failed:', err);
    }
}

Subscribing to Backend Events (aura.on)

JAVASCRIPT 
// Listen to background telemetry from C++
const unsubscribe = aura.on('telemetry', (data) => {
    document.getElementById('cpu-val').innerText = data.cpu_usage + '%';
});

Client-Side SPA Routing (aura.router)

Define views declaratively using the data-aura-view attribute:

HTML 
<nav>
    <button data-aura-route="/dashboard" class="active">Dashboard</button>
    <button data-aura-route="/settings">Settings</button>
</nav>

<div data-aura-view="/dashboard" class="active">
    <h1>Dashboard View</h1>
</div>

<div data-aura-view="/settings">
    <h1>Settings View</h1>
</div>

❓ Troubleshooting & FAQ

Q: How do I distribute my application to end users?

Simply distribute the dist/my-app.exe executable! Because WebView2 is built into Windows 10 and 11, users can double-click and run it with zero installation required.

Q: Can I use modern web frameworks like React or Svelte?

Yes. Set your bundler (Vite, Webpack, etc.) to output into the ui/ directory. AuraUI will bundle your compiled assets directly into the C++ binary.
